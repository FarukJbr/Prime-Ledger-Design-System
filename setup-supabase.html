השלב הראשון — Supabase
1

פתיחת חשבון ופרויקט

היכנסו ל‑supabase.com ולחצו Start your project. אפשר להתחבר עם חשבון Google.

  • לחצו New project
  • שם: prime-ledger
  • בחרו סיסמה למסד (שמרו אותה בצד) ואזור Europe (Frankfurt)
  • לחצו Create new project והמתינו דקה-שתיים שייווצר
התוכנית החינמית של Supabase מספיקה בהחלט להתחלה — כולל מסד נתונים, התחברות ואלפי משתמשים.
2

יצירת הטבלאות

בתפריט הצדדי בחרו SQL Editor → New query. פתחו את הקובץ supabase-schema.sql שהכנתי, העתיקו את כל התוכן, הדביקו בעורך ולחצו Run (▶).

זה יוצר אוטומטית את טבלת הלקוחות, הרשאות האבטחה, ורשימת המנהלים — הכל בפעם אחת.

אם הופיעה הודעת Success — הכל תקין. אפשר לראות את הטבלה החדשה תחת Table Editor → clients.
3

העתקת המפתחות

בתפריט: Project Settings (גלגל שיניים) → API. שם תמצאו שני ערכים:

  • Project URL — כתובת כמו https://abcd1234.supabase.co
  • anon public — מפתח ארוך תחת "Project API keys"

פתחו את הקובץ config.js שלנו והדביקו את שני הערכים:

window.PL_CONFIG = { SUPABASE_URL: 'https://abcd1234.supabase.co', SUPABASE_ANON_KEY: 'eyJhbGciOi...המפתח-הארוך-שלכם', ADMIN_EMAILS: ['info@primels.co.il'], };
המפתח anon public מיועד לדפדפן ובטוח לפרסום — האבטחה האמיתית נאכפת ע״י ה‑RLS שהקמנו בשלב 2. לעולם אל תדביקו את מפתח ה‑service_role.
4

הגדרת התחברות וקישור המנהל

ב‑Supabase: Authentication → Providers — ודאו ש‑Email מופעל. לבדיקות מהירות אפשר לכבות זמנית את "Confirm email" תחת Authentication → Sign In / Providers, כדי שלא תצטרכו לאשר כל מייל.

כדי שתקבלו הרשאת מנהל: ודאו שהאימייל שלכם מופיע גם ב‑config.js (ADMIN_EMAILS) וגם בטבלת admins במסד. הירשמו דרך עמוד הכניסה עם אותו אימייל — ומאותו רגע פאנל הניהול פתוח רק לכם.

השלב השני — האתר באוויר
5

העלאה לאינטרנט וחיבור הדומיין primels.co.il

אחרי שנסיים את האתר, מעלים את תיקיית האתר לאחסון. הדרך הפשוטה: Netlify או Vercel (חינם) — גוררים את התיקייה והאתר עולה תוך דקה.

  • מעלים את האתר → מקבלים כתובת זמנית (כמו prime-ledger.netlify.app)
  • בלוח הבקרה של האחסון: Add custom domain → primels.co.il
  • אצל ספק הדומיין שלכם מעדכנים את רשומות ה‑DNS לפי ההוראות שהאחסון נותן
  • תוך כמה שעות הדומיין מחובר — עם תעודת אבטחה (HTTPS) אוטומטית
כשנגיע לשלב הזה — אכין לכם חבילת העלאה מסודרת + הוראות מדויקות לספק הדומיין הספציפי שלכם. לא צריך לעשות את זה לבד.
